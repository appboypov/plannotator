# Architecture decisions

- ADR 0003 keeps fork code in separate modules and upstream call sites small.
- ADR 0005 keeps one upstream page server per Review.
- ADR 0006 puts decisions in the service.
- ADR 0007 keeps CLI commands as clients and doors limited to their Visibility.
- ADR 0008 gives each Review one listener holder.
- ADR 0009 applies the upstream-server pattern to PR Reviews.
